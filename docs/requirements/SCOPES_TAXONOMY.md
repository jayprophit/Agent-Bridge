# SCOPES — Provisional Taxonomy Record (v0.8, requirements only)

**Status: PROVISIONAL term. Not Aetherius OS. Not Genesis. Not Agent
Bridge itself. Not legally cleared branding. No runtime implemented.**

SCOPES = **S**ensing, **C**ontrol, **O**rchestration, **P**rogramming,
**E**xecution, **S**afety — the future unified digital-to-physical
orchestration layer.

## Conceptual stack

AETHERIUS OS (operating-system/platform) → GENESIS (master AI/
intelligence/entity) → AGENT BRIDGE (universal interoperability/runtime
bridge) → SCOPES (physical sensing/control/orchestration) →
APPLICATIONS (Poietek and future domain apps).

## Safety separation (binding rule)

GENESIS/AGENT → INTENT → SCOPES TASK ORCHESTRATOR → PLANNER → SAFETY
SUPERVISOR → REALTIME CONTROL → DRIVER/PLC/CONTROLLER → HARDWARE.
AI expresses intent; it never issues unsafe raw physical control.

## Coverage scope (recorded, not built)

3D printers, CNC, laser cutters, robots, drones where appropriate, smart
home/industrial equipment, PLCs, SCADA, factory machinery, IoT/embedded
(Arduino/ESP/Raspberry-Pi class, microcontrollers), sensors, actuators,
motor controllers, fabrication/digital-manufacturing, building automation,
energy/lab/agricultural systems, other cyber-physical systems.

## Physical domain taxonomy (canonical labels)

ROBOTICS, IoT, EMBEDDED SYSTEMS, CYBER-PHYSICAL SYSTEMS, OPERATIONAL
TECHNOLOGY — OT, INDUSTRIAL CONTROL SYSTEMS — ICS, PLC SYSTEMS, SCADA,
MES, DIGITAL FABRICATION, SMART MANUFACTURING, EDGE CONTROL, AUTOMATION,
MACHINE CONTROL, SENSOR NETWORKS, ACTUATOR NETWORKS, ROS / ROS 2,
MICROCONTROLLERS, INDUSTRIAL NETWORKS.

These are domain labels/capabilities within the physical-system layer
(recorded here and as domain_tags on PHY registry entries), not separate
v0.8 implementations — none of these physical systems are implemented in
v0.8.

## Ownership

SCOPES-owned requirements in this registry carry owner SCOPES and status
FUTURE_SCOPES (or ARCHITECTURE_READY where bridge analogues exist:
trust, protocol translation, artifacts-as-twins, dashboards).
Safety-critical items belong to GENESIS_PHYSICAL_LAYER.
