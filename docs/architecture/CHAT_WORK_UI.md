# Chat / Work UI (v0.8, Part H)

Two layouts, one session/agent/memory/history/tools/avatar: CHAT (large
avatar, voice, transcript, attachments, tool status, notifications) and WORK
(workspace/editor/preview/terminal + agent panel with avatar window,
conversation, tool status, plan/progress, approvals, artifacts/diffs).
Same DefaultAgent, same session, same tools throughout.
